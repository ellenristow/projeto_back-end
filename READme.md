# Marmita

Marmita is a PHP-based website created to help people who rely on daily meal prep and are looking for new recipe ideas. This project is in its early stages but has great potential for expanding its features in the future.

## Current Features:

**Public Access and User Accounts:**
The site is open to all users, with no account required to browse. However, users have the option to create an account to manage their recipes in a more personalized way.

**Recipe Creation and Editing:** Registered users can create and edit their own recipes, sharing ideas and helping others in the community.

## Upcoming Features:

**Recipe Interaction:** We plan to add a like feature, allowing users to engage with recipes shared by other community members.
**Favorites Page:** Soon, users will be able to save favorite recipes, building a personalized list of meal ideas for easy access.
